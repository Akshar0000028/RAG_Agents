# RAG Agents

A collection of Retrieval-Augmented Generation experiments focused on grounding LLM responses with external knowledge.

## Topics explored

- Document ingestion and chunking
- Embeddings and vector search
- Retrieval pipelines
- Prompt construction
- Agent-based RAG workflows
- Evaluation and iteration

## Tech focus

Python · LangChain · LLMs · Embeddings · Vector Databases

## Status

Experimental / learning repository. Individual examples are intentionally kept small and focused.
